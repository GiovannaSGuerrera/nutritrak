# Documentos aprovados pelo operador

Fornecer privacy.md e terms.md aprovados pelo responsável/assessoria jurídica. O build copia estes textos públicos para apps/api/dist/legal, incluído no pacote serverless existente. O startup produtivo exige ambos; nenhuma minuta fictícia foi criada para contornar o gate. Não colocar segredos ou informações pessoais nesses textos. Definir controlador/contato/base legal de dados sensíveis, operadores, retenção clínica e atendimento aos titulares antes de clientes reais.
