# Documentos do operador

Forneça `privacy.md` e `terms.md` aprovados pelo responsável e assessoria jurídica antes de executar produção. São servidos como texto público com versão SHA256 em /privacy e /terms. O startup de produção recusa documentos ausentes. Defina controlador, contato, bases legais de dados de saúde, finalidade, operadores, retenção e atendimento dos titulares. Não há política jurídica fictícia neste diretório. Não inclua dados pessoais ou segredos nos documentos públicos.
